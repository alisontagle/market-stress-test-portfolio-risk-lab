# Analysis notebooks

After learning the dashboard code, create three notebooks here:

1. `01_data_analysis.ipynb` — explain data cleaning, returns, and correlations.
2. `02_portfolio_optimization.ipynb` — derive and discuss the optimization results.
3. `03_stress_testing.ipynb` — interpret drawdown, VaR, CVaR, and scenarios.

Do not submit empty or unexplained notebooks. Your written interpretation is part of the project.
